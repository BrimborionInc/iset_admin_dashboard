# Training Docs

Status: source training/reference material.

This directory contains extracted staff training content and original form/source files. It is useful for PATH workflow language, staff expectations, help-panel tone, and compliance context, but it is not implementation truth.

## How To Use

- Use `TRAINING_MODULES_September_2025_extracted.md` as the baseline for coordinator-facing help panels and staff workflow guidance when `docs/AGENTS.md` points here.
- Treat DOCX forms and text lists as source artifacts; verify against current generated-form, document-signing, and supporting-document behavior before changing code.
- Do not copy long training passages into UI copy. Translate the relevant expectation into short task-focused staff guidance.

## Cleanup Rule

Keep training extracts and original artifacts separate from current implementation docs. If a training artifact becomes obsolete, mark it historical or superseded rather than silently rewriting it.
