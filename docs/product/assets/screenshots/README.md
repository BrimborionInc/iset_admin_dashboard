# Approved PATH Content Screenshots

Status: current catalogue; no screenshot is approved merely because it exists in `tmp/` or a smoke-test output directory.
Audience: content producers and reviewers.
Last Updated: 2026-08-21

## Catalogue

No marketing/manual screenshot has completed the new approval workflow yet.

Use `docs/product/dev-screenshot-runbook.md` for capture, privacy review, manifest, caption, alt-text, and promotion requirements.

## Required Entry For Each Approved Image

For every image added to this directory, record:

- image ID and filename;
- source request ID;
- surface, role/persona, and state;
- synthetic/stubbed data mode;
- current PROD-equivalent or DEV-preview status;
- source commit(s), capture date, viewport, and transformations;
- privacy and product reviewers;
- approved caption and alt text;
- superseded image, if any.

Do not store raw screenshots, real-data captures, credentials, browser session artifacts, HAR files, or unreviewed images in this directory.
