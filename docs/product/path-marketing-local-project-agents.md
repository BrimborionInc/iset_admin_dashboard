# PATH Marketing Materials Local-Project Guidance

This folder is a curated evidence workspace for producing PATH marketing materials.

Before beginning any task:

1. Read `chatgpt-project-instructions.md` completely and follow the instructions inside its main text block.
2. Treat `path-capability-source-pack.md` as the controlling product-status and publishing boundary.
3. Use the file named **path-promo-website-source-brief.md** as marketing raw material, not as independent proof that every capability is deployed.
4. Use `codex-support-handoff.md` whenever a fact, current interface behavior, release status, screenshot, or supporting artifact requires repository or DEV verification.
5. Follow `dev-screenshot-runbook.md` for every interface-image request.

For the initial marketing project, read and execute `path-marketing-project-starter-prompt.md` after loading the instructions above.

Never invent product claims, outcomes, metrics, testimonials, integrations, certifications, interface labels, or release status. Never use real applicant, client, staff, case, application, message, document, or financial data in marketing content or screenshots.
