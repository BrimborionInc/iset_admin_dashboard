# ESDC ILMP / ALMP 1.4 Reference

This folder contains reference material for generating Indigenous Labour Market Programs (ILMP) XML files that conform to the ALMP XML schema version **1.4**.

The ILMP / ALMP schema is used by ESDC for:
- Indigenous Skills and Employment Training (ISET)
- Skills and Partnership Fund (SPF)

These files give Codex enough structure and code sets to generate valid ILMP XML.

Source: ILMP XML Data Exchange Guide, SchemaVersion 1.4 (Nov 2022).
